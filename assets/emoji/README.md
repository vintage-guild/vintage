# Emoji art

Vintage's own Discord emoji, generated by `scripts/build-emoji-art.mjs` and uploaded as the app's
emoji by `scripts/discord-emojis.mjs` (listed in `scripts/discord-emojis.json`).

| Files | What | License |
|---|---|---|
| `status_*.png`, `info_*.png` | Outline icons from [Tabler Icons](https://tabler.io/icons), tinted with Vintage's signup colors | MIT, © Paweł Kuna (Tabler Icons) |
| `square_*.png` | Class-colored squares (WoW class colors) | Part of Vintage; the colors are a WoW convention |

Don't edit the PNGs by hand: change the script and re-run it. Blizzard's class and spec icons are
uploaded straight from Wowhead's CDN and are never stored here.
