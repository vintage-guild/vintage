# Support

- **Guild members:** ask in the guild Discord first; officers know the setup best.
- **Bugs and feature ideas:** open an issue with the [issue forms](https://github.com/vintage-guild/vintage/issues/new/choose).
- **Contributing:** start with [CONTRIBUTING.md](CONTRIBUTING.md) and [SETUP.md](SETUP.md).
- **Security problems:** report privately, as described in [SECURITY.md](SECURITY.md). Don't
  open a public issue.

This is a volunteer guild project; replies may take a few days.
