# Feature docs

Lifecycle: `proposed/` → `active/` → `completed/`. Each feature gets a folder with a
`<feature>.plan.md` (what and why, tasks, decisions) and, when needed, a `<feature>.spec.md`
(contracts and behavior).

**Rule:** update the plan in the same PR as the work. Decisions go in the feature doc and,
when they affect every contributor, in the Decisions table in [AGENTS.md](../../AGENTS.md).
