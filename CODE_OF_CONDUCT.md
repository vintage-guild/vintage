# Code of conduct

Vintage is a guild first. The same standards apply here as in raid chat and Discord: be
someone people want to raid with.

## Expected

- Be respectful and assume good intent, in issues, reviews, and commit messages.
- Critique code and ideas, not people.
- Help newer contributors; explain the why behind a requested change.
- Disclose when an AI agent wrote or reviewed a change, and take responsibility for what you
  submit either way.

## Not acceptable

- Harassment, insults, or discriminatory language of any kind
- Personal attacks, trolling, or sustained disruption
- Publishing anyone's private information (including other members' Discord or character data)
  without permission

## Enforcement

Guild officers maintain this repo and enforce this code. Report problems privately to an
officer on Discord, or through the repository's security advisory form for anything sensitive.
Officers may remove comments, close issues or PRs, or remove contributor access.

This code is adapted from the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
